# Arcanum

Letture di tarocchi dal vivo: una lettrice, una domanda, le carte che rispondono. In chat, a voce o in video.

**Gioca dal browser:** https://arcanum.bais.info

**App Android:** [scarica l’ultima versione](https://github.com/bdbais/arcanum-releases/releases/latest/download/Arcanum.apk)

Per installarla, apri il file scaricato e consenti l’installazione da questa fonte quando Android lo chiede. L’app controlla da sola se esce una versione nuova e ti propone di scaricarla.

Questo repository contiene solo le versioni pubblicate e il file `version.json` usato per gli aggiornamenti. Privacy: https://arcanum.bais.info/privacy.html

Un progetto di [Bais](https://bais.info).
